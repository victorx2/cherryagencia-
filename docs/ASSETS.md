## Cómo usar

1. **Hero:** lote `Foto mía` / `Trabajando` ~17:58 (`docs/HERO.md`). Stand CMQA y live con pantalla de cliente → `evento`, no LCP.
2. Piezas editoriales (F1, Barça, flyers) en bento de **cultura**, no como logo de Cherry.
3. Metáforas técnicas (rodamiento, camisa, torre) en **ingeniería**.
4. Collages infantiles o fan-art → `excluir` del hero.

Las piezas de clientes (CMQA, RiM, podcast) ilustran **oficio**, no identidad Cherry.
