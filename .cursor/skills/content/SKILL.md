# Content

## Objetivo

Textos originales de Cherry Agencia para cultura e ingeniería. Emocionales y creíbles. Nunca el copy de millonariosconscientes.co ni de cherryagencia.vercel.app.

## Cuándo utilizarlo

Al redactar o editar headlines, subheads, beneficios, FAQ, planes, testimonios, meta description o CTAs.

## Reglas

Debe ser: claro, emocional, aspiracional, humano, creíble, directo.

Evitar:

- Promesas de riqueza garantizada
- Claims imposibles
- Lenguaje manipulador
- Falsa urgencia (solo 24h, últimos cupos inventados)
- Testimonios inventados o cifras de ingresos
- “La mayor comunidad hispanohablante…” u otros ecos de la referencia

Precios: `[PRECIO]`.  
Testimonios: reales o `[Testimonio pendiente — reemplazar con historia real]`.

Énfasis: una locución en serif + cherry o gold por headline.

CTA: `QUIERO EMPEZAR →` / `HABLAR CON CHERRY` / `VER EL OFICIO` — no el literal de la referencia.

Datos en `src/data/` cuando exista código.

## Proceso

1. Leer `docs/BRIEF.md` y, si es el above-the-fold, `docs/HERO.md` (lote 5:58 Foto mía / Trabajando).
2. Escribir para un escaneo de 5 segundos (qué es, para quién, siguiente paso).
3. Cortar adjetivos de relleno (“único”, “revolucionario”, “élite”).
4. Pasar el filtro no-clone: si suena a la referencia, reescribir.

## Checklist

- [ ] Español natural
- [ ] Sin claims financieros
- [ ] Sin textos de las webs de referencia
- [ ] Placeholders visibles donde falte lo real
- [ ] CTA no en cada párrafo
- [ ] FAQ honestas

## Errores que evitar

- Inventar otra fundadora o mencionar a Irma. Cara pública = Raizel.
- Poner otro rostro en el hero (PAZ, stock, cliente CMQA a cuerpo entero)
- Headline script naranja “Comunidad” encima de Raizel
- Inventar clientes o premios
- Urgencia de countdown
- Mezclar voz de guru con voz de agencia
